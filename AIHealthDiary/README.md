# AI 健康日记与数据管理系统

## 项目简介

这是一个基于 Windows 平台的健康数据管理应用程序，使用 C# 和 Windows Forms 开发。系统提供健康数据记录、饮食运动管理、AI 智能分析和周报生成等功能，帮助用户全面管理个人健康。

## 功能特性

### 1. 用户管理
- 添加、编辑用户信息
- 记录身高、体重、年龄等基础数据
- 自动计算 BMI 指数和基础代谢率

### 2. 健康数据记录
- 体重记录与追踪
- 睡眠时间记录
- 血压监测（收缩压/舒张压）
- 心率记录
- 历史数据查询与展示

### 3. 饮食记录
- 记录每日三餐及加餐
- 记录食物名称、份量
- 记录热量、蛋白质、碳水化合物、脂肪、膳食纤维
- 营养成分分析

### 4. 运动记录
- 记录运动项目和类型
- 记录运动时长和消耗热量
- 记录运动强度和心率
- 运动历史查询

### 5. AI 智能分析
- **健康数据分析**：综合分析用户的健康数据，给出评分和建议
- **饮食计划生成**：根据用户情况生成个性化饮食计划
- **运动计划生成**：制定科学的运动方案
- **健康周报**：自动生成周健康总结报告

## 安装说明

### 环境要求
- Windows 10 或更高版本
- .NET 8.0 SDK 或运行时

### 安装步骤

1. **克隆或下载项目**
   ```bash
   git clone <项目地址>
   cd AIHealthDiary
   ```

2. **还原 NuGet 包**
   ```bash
   dotnet restore
   ```

3. **编译项目**
   ```bash
   dotnet build
   ```

4. **运行程序**
   ```bash
   dotnet run
   ```

   或者直接在 Visual Studio 中打开项目并运行。

## 使用说明

### 首次使用

1. 启动程序后，点击右上角的"+ 添加用户"按钮
2. 填写用户基本信息（姓名、性别、年龄、身高、体重）
3. 保存后，系统会自动计算 BMI 和基础代谢率

### 记录健康数据

1. 在左侧导航栏选择"健康记录"
2. 填写日期、体重、睡眠时长、血压、心率等信息
3. 点击"保存记录"按钮
4. 右侧列表会显示历史记录

### 记录饮食

1. 在左侧导航栏选择"饮食记录"
2. 选择日期和餐次（早餐/午餐/晚餐/加餐）
3. 填写食物名称、份量、热量和营养成分
4. 点击"保存记录"按钮

### 记录运动

1. 在左侧导航栏选择"运动记录"
2. 选择日期，填写运动名称和类型
3. 记录运动时长、消耗热量和强度
4. 点击"保存记录"按钮

### AI 分析功能

1. 在左侧导航栏选择"AI 分析"
2. 点击相应的功能按钮：
   - **健康数据分析**：查看综合健康报告
   - **生成饮食计划**：获取个性化饮食建议
   - **生成运动计划**：获取科学运动方案
   - **生成健康周报**：查看周健康总结

### 查看周报

1. 在左侧导航栏选择"周报"
2. 系统会自动生成本周健康报告
3. 可以导出报告为文本文件

## 数据库说明

系统使用 SQLite 本地数据库，数据库文件为 `health_diary.db`，包含以下表：

- **Users**：用户表，存储用户基础信息
- **HealthRecords**：健康记录表，存储每日健康数据
- **Diets**：饮食记录表，存储饮食信息
- **Exercises**：运动记录表，存储运动信息

## AI 功能说明

当前版本的 AI 功能使用基于规则的算法实现（Mock 版本），主要包括：

### 健康分析算法
- BMI 计算与分类
- 体重趋势分析
- 睡眠质量评估
- 血压状态判断
- 饮食热量评估
- 运动频率统计

### 计划生成算法
- 根据用户基础代谢率计算推荐热量
- 根据运动水平生成运动方案
- 营养均衡的饮食搭配建议

### 扩展为真实 AI
如需接入真实 AI API（如 OpenAI），请修改 `AIAnalysisService.cs`：

1. 在构造函数中传入 API Key
2. 实现 `UseRealAI` 逻辑分支
3. 调用相应的 AI API 进行分析

示例代码框架已在 `AIAnalysisService.cs` 中预留。
